# Universal Website Constructor — Demos

**100% static** HTML/CSS/JS for GitHub Pages. No PHP, no server.

## GitHub Pages

Settings → Pages → deploy from **`/docs`** on `main`.

## Local preview

```bash
npx serve docs
```

## Use

Open **`docs/index.html`** — pick any demo. Browser back returns to the list.

**Login as Demo Admin** (footer) unlocks the admin panel preview.

Interactive demos save to `localStorage` in your browser only.
